# Capstone Task Manager

## Project Overview

A responsive Task Manager web application built using HTML, CSS, and JavaScript.

## Features

- Login Simulation
- Add Task
- Complete Task
- Delete Task
- Search Task
- localStorage Support
- Responsive Design

## Technologies

- HTML5
- CSS3
- JavaScript

## Folder Structure

capstone-task-manager/
├── css/
│ └── style.css
├── js/
│ └── app.js
├── images/
├── index.html
└── README.md

## How to Run

1. Open the project in VS Code.
2. Start Live Server.
3. Login using any username.
4. Add, search, complete and delete tasks.
